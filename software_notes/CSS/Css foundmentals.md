### The Cascade
اللغة ببترجم من المتصفح بشكل عامودي من فوق لتحت (بمعني انو لو في خاصيتين بأثرو علي نفس الحاجه فاللي اتكتبت الاخر هي اللي هتفوز)
```css
p {
	background: orange;
	font-size: 24px;
}

p {
	background: red;
}
```
هنا دا معناه انو البراغراف في النهاية هيتلون باللون الأحمر عشان السيلكتور التاني لغي السيلكتور الأول
```css
p {
  background: orange;
  background: red;
}
```
وهنا كمان نفس الفكرة الخاصية التانية هتلفي الخاصية الاولي فبتالي البراقرافات هتتلون بالاحمر والبسبب زي ماقلنا انو الكاسكيد بيقرا الكود من فوق لتحت فبتالي اللي اثر اخر حاجه علي عنصر معين هو اللي هيتطبق

ولكن مش دي الحاله دايما في حالات احيانا بتطبق الخاصية اللي اتكتبت الأول ازاي؟؟
### Selectors Weight
كل سيلكتور في السي اس اس ليه وزن معين في بعيدا عن موقعة في الكود فلو في سيلكتور وزنة اكبر من سيلكتور تاني، الاقوي هو اللي بيطبق بعيدا عن موقة في الكود

اضعف انواع السليكتوز وزنا هو اللي بيختار باسماء العناصر ونقدر نقول انو قيمته في الأحاد `001` الاقوي منه بشويه هو الكلاس سيلكتور ودا نقول انه في خانه العشرات `010` والاقوي خالص هو الاي دي سليكتور ونقدر نقول انه في خانه المئات `100`

```html
<p id="food">...</p>
```

```css
#food {
  background: green;
}
p {
  background: orange;
}
```
هنا من الطبيعي جدا انو لون البراقاف هيكون اخضر عشان الاي دي سليكتور افوي من التاني

تقدر تدمج السيلكتورز مع بعض عشان تكون وزن معين
```html
<div class="hotdog">
  <p>...</p>
  <p>...</p>
  <p class="mustard">...</p>
</div>
```

```css
.hotdog p {
  background: brown;
}
.hotdog p.mustard {
  background: yellow;
}
```

لما بندمج السيلكتورز بتتقري من اليمين للشمال يعني ف اول سيلكتور انا بقول "خد كل عناصر البراقراف اللي موجود جواد عنصر من كلاس هوتدوج ولونهم بالبني"
اما في التاني بقول "خد اي براقراف من كلاس موسطارد اللي موجود جوا عنصر من كلاس هوتدوج وحلي لونه اصفر"

اللي هيحصل انو كل اللي البرفرافات اللي فوق هتتلون باللون البني معادا الاخير اللي متحدد فيه كلاس هيتلون باللون الاصفر ليه عشان وزن السيلكتور الاول كان `011` بينما وزن التاني كان `021`

#### الأحجام
ممن نتعامل بالبيكسل وممكن نتعامل بنسب 

```css
p {
  font-size: 14px;
}
```
هنا بقول انو حجم خطي 14 بيكسل
```css
.col {
  width: 50%;
}
```
وهنا بقول انو عرض العنصر بتاعي بيساوي نص عرض ابوه
```css
banner {
  font-size: 14px;
  width: 5em;
}
```
وهنا بقول انو عرض العنصر بتاعي بيساوي 5 اضعاف حجم خطه ولو الخط بتاعته مش متحدد فيبقي خط ابوه اي يعني $$5 * 14 = 70$$
### Fonts
ازاي نتعامل مع الفونت في السي اس اس ؟؟
عشان تحدد لون خط لعنصر معين بستعمل الخاصية `color`
```css

color: green;
}
```
وعشان تغير الخط بتستعمل 
```css
font-family: cario, sans-serif;
```
لو الخط الاول مش متاح هيتم استخدام الخط اللي بعده
بنستخدم `font-size` عشان نغير خجم الحط
```css
font-size: 12px;
```
بسنتخدم `font-style` عشان نغير شكل الخط
```css
font-style: italic;
```
عشان تحدد المسافة بين كل سطر استعمل 
```css
line-height: 12px;
```
عشان نتسنتر الكتابة جوا عنصر خلي ارتفاع السطر وارتفاع العنصر واحد
```css
.btn {
  height: 22px;
  line-height: 22px;
}
```

### Box model
#### Block or inline?
كل عنصر من عناصر الكود بيتعرض في واحد من شكلين اما `block` ودا معناه انو العنصر هياخد كامل المساحه بعيدا عن محتواه وفي ال `inline` ودا معناه انو العنصر بياخد مساحه فقط علي قد محتواه وممكن عنصر تاني يجي يكمل جمبه
نقدر نغير الخاصية display عشان نديها احد القيم 
```css
p {
  display: block;
}

p {
  display: inline;
}
```
وفي كمان نوع تالت خطير 
```css
p {
  display: inline-block;
}
```
 ودا هيخلي العنصر ياخد خواص البلوك اللي هي الحدود والمساحة `paddin - margin` بس هيظهر علي نفس الخط
 وأخيرا القيمه `none` هتخفي العنصر بالكامل من الصفحه

#### What is the box model
تبعا لنموذج الصندوق اي عنصر في الصفحه هو عبارة عن مسطتيل ليه خواص زي الطول والعرض والحواف والمساحه `height width borders margin padding`
```css
div {
  border: 6px solid #949599;
  height: 100px;
  margin: 20px;
  padding: 20px;
  width: 400px;
}
```
